# Your Digital Canvas

NovaDrop is a single-page personal branding website for a solo creative developer — someone who both designs and builds digital products. It presents their identity, selected work, technical skills, and a way to get in touch, all in one scrollable experience. Think of it as a living résumé that shows rather than tells.

Make sure to include a Navigation Bar (Header), Hero Section, Ticker / Marquee Strip (Text), About me, Experience and featured works and footer sections.

I will later tell you the other features to add, but now just build the workable website.
